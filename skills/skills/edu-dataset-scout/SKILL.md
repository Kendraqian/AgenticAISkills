# 教育行业数据集侦察兵 (Edu Dataset Scout)

把“全网搜集高校开放数据”这件事，沉淀为一套可复用的自动化调研流水线，旨在为百度教育生态运营提供精准的数据合作线索。

## 1. 业务场景摘要
本 Skill 专为教育生态运营团队设计。当需要针对特定区域（如：大湾区、长三角）或特定学科（如：理科、外语）寻找大模型微调/测评语料时，该工具能自动化完成“搜索-分层-建表”的全过程，替代繁琐的案头研究工作。

## 2. 技能定义 (Skill Definition)

### 核心目标
1. 监控 2025-2026 年间高校及科研院所的最新数据集发布动态。
2. 对数据集进行 0-100 分的“适配性打分”。
3. 产出结构化的《教育数据集调研报告》表格。

### 适用 Agent
- 适配具有联网搜索与表格处理能力的 Agent (如 Ernie Agent, Claude Code)。

## 3. 执行规范 (Instructions)

### Step 1: 多源检索与采集
- **关键词策略**：使用 `[目标区域/学校] + "最新发布" + "数据集" + "2026/2025"` 的组合。
- **核心渠道**：优先检索 C9 联盟官网、国家基础学科公共科学数据中心、arXiv 论文配套数据、HyperAI 等专业平台。

### Step 2: 信息提取与标准化
对搜索到的每个数据集，必须提取以下核心字段：
- **发布主体**：高校名称或实验室名称。
- **数据集名称**：官方命名。
- **发布时间**：精确到月份。
- **数据类型**：多模态（视频/图文）、知识图谱、纯语料、画像类。

### Step 3: 价值评估与分层
按以下口径进行 0-100 评分（权重：业务匹配度 40%，时效性 30%，证据完整度 30%）：
- **S (90-100)**：极高价值，含大量教材、真实考试数据。
- **A (80-89)**：高价值，含学术对话或知识图谱。
- **B (70-79)**：中等，适合通用测试。
- **C/D (<70)**：低优先级，默认不进入核心表格。

### Step 4: 文心适配性分析
针对每个 S/A 级数据集，必须给出至少一条**技术建议**：
- 例如：“适合文心长文本 RAG 增强”、“适合教育 Agent 对话调优”、“适合多模态视觉理解微调”。

## 6. 常见失败模式 (Common Failure Modes)
- **时效性不足**：如果只返回 2023 年及以前的数据，视为执行失败。
- **缺乏适配性分析**：表格中若没有“文心适配性建议”列，视为未完成任务。
- **来源不明**：必须保留原始发布链接或官方公告出处。
